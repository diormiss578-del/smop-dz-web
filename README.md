# SMOP DZ — Algerian Women's PCOS & Hormonal Health Platform

SMOP DZ is a comprehensive women's health and PCOS (Polycystic Ovary Syndrome / متلازمة تكيس المبايض) wellness management web application tailored for women in Algeria. Rewritten from Android Jetpack Compose into React + TypeScript + Vite with full RTL support (Arabic / English toggle).

## Features

- **Learn & Research Library**: Clinical breakdowns of PCOS types (Insulin Resistant, Inflammatory, Adrenal, Post-Pill), article of the day, search functionality, and expert medical guides.
- **Specialists Directory**: Directory of certified PCOS clinical nutritionists and low-cortisol fitness coaches (Blida state and national coverage), star ratings, reviews, and real-time confidential chat with simulated feedback.
- **Natural Eco-Stores Directory**: Directory of local Algerian suppliers offering gluten-free bakeries, keto sweets, pure Sidr honey, and organic supplements with promo codes and dynamic route navigation HUD.
- **Holistic Wellness Programs**: Standard and tailored PCOS wellness protocols with daily anti-inflammatory recipes, benefits breakdowns, and consultation booking.
- **Cortisol-Conscious Fitness**: Low-impact strength training, yoga & meditation, dance & cardio workouts, local women's gym directory in Blida, and premium routine unlock.
- **Artisanal Home Kitchens**: Directory of certified home cooks preparing diabetes-friendly and PCOS-safe traditional Algerian meals (tajines, barley couscous, almond baklawa) with full interactive order reservations.
- **Personal Health Dashboard**:
  - Live biometric tracking with BMI calculation and PCOS type assessment based on symptoms.
  - Menstrual cycle and ovulation tracker with chronological logs.
  - Daily therapeutic reminders for supplements, medications, and clinical appointments.
  - Kitchen meal reservation history with cancellation management.
- **QR Code Sharing**: Interactive QR code generator with brand color customization, URL copying, and native sharing.

## Technology Stack

- **Framework**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **QR Code**: QRCode SVG
- **Dev Server**: Vite (port 3000, 0.0.0.0)
